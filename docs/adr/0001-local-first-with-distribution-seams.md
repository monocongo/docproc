# Stay local while preserving distribution seams

Use one local polling worker with SQLite, versioned MinIO, local OpenSearch, Streamlit, Docling, and host Ollama; preserve stable identities, versioned records, immutable Artifact references, fenced Work claims, authoritative metadata, and rebuildable Projections so a later evidence-backed initiative can replace execution or storage boundaries. Do not build queues, a second database/backend, Kubernetes, AWS infrastructure, or remote model serving now: that complexity has no measured requirement, while the detailed [local-to-distributed evolution constraints](../decisions/local-to-distributed-evolution.md) keep future migration explicit rather than claiming cloud readiness.
