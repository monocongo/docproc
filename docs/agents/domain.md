# Domain docs

This is a single-context repository.

Before working in the codebase:

1. Read root `CONTEXT.md` when it exists.
2. Read relevant records under `docs/adr/` when they exist.
3. Use the vocabulary in `CONTEXT.md`.
4. Surface conflicts with accepted ADRs rather than silently overriding them.

`CONTEXT.md` and `docs/adr/` are created when the project has durable domain language or decisions to record.
